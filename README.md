# Public Rent a Car

This release is a noncommercial demonstration and is excluded from search indexing.

Website source for Public Rent a Car in Belgrade.

Use Node.js 24.

```sh
npm ci
npm run build
npm run preview
```

The Vite production output is `dist/`. Use `npm run dev` for local development.
The optional `SITE_URL` build setting supplies the public origin.

The 2019 Škoda Karoq model is illustrative and differs from the individual rental
vehicle. Model attribution and license are in
`public/assets/models/karoq-LICENSE.txt`.

Hosting credentials are configured separately. The optional deployment workflow
requires its exact project configuration and explicit enable variable.
